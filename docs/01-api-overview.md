# OpenBD API 概要

## OpenBDとは

OpenBD（オープンビーディー）は、日本の書籍の書誌情報と書影を無料で提供するAPIサービスです。書店、図書館、メディア、サービス開発者など、誰でも自由に利用できます。

## サービスの背景と歴史

### 設立の経緯
- **運営**: 株式会社カーリル、株式会社版元ドットコムが共同で運営
- **目的**: 書籍情報の流通促進、出版業界のデジタル化支援
- **特徴**: 無料、高速、オープンなAPI提供

### データソースの変遷

#### JPROデータ配信停止（2023年）
2023年6月5日、日本出版インフラセンター（JPO）からの書誌データ配信が停止されました。

**停止の理由**:
- JPROの利用規約変更
- データ配信の持続性の問題

#### 国立国会図書館データへの移行
JPRO停止後、OpenBDは国立国会図書館が提供するCC-BY（クリエイティブ・コモンズ表示）ライセンスのデータに切り替えました。

**新体制の特徴**:
- **版元ドットコム会員社**: 626社の詳細書誌データ + 書評・在庫情報
- **国立国会図書館データ**: 基本書誌情報（ISBN、タイトル、著者、出版社など）
- **総データ量**: 約163万件のISBN

## データ規模と性能

### データ規模
- **総ISBNデータ数**: 約163万件
- **版元ドットコム会員社**: 626社
- **更新頻度**: 継続的に更新

### 性能指標
- **レスポンス速度**: 1件あたり1ミリ秒以下
- **一括取得**: 最大1,000件のISBNを1リクエストで取得可能
- **インフラ**: 複数のデータセンターに分散配置
- **CDN対応**: 書影画像の高速配信

## 基本的な制限事項

### 検索方法の制限
- **ISBN検索のみ対応**: 著者名や書名での直接検索は不可
- **全文検索非対応**: タイトルや内容での検索機能なし

### データの注意点
- **近刊情報の変更**: 発売前の書籍情報は変更される可能性あり
- **データの網羅性**: 版元ドットコム会員外の書籍は基本情報のみ
- **データの保証**: 情報の正確性や完全性は保証されない

### 推奨される利用方法
- **適切なキャッシュ**: データを定期的に更新することを推奨
- **データ改変禁止**: 取得したデータの改変は禁止
- **用途制限**: 書籍の紹介・宣伝目的での利用が前提

## 利用規約

### 利用条件
- 書籍の紹介・宣伝目的での利用
- データの改変禁止
- 定期的なデータ更新の推奨

### ライセンス
- **版元ドットコムデータ**: 各社の提供条件に準拠
- **国立国会図書館データ**: CC-BY（クリエイティブ・コモンズ表示）
